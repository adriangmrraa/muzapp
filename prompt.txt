Implementar integración completa entre el agente de Telegram (admin) y el agente de ventas de WhatsApp en el proyecto muzapp.
CONTEXTO: El bot de Telegram actualmente opera sin saber lo que pasa en las conversaciones de WhatsApp. Necesita poder VER el contexto de ventas, TOMAR CONTROL de conversaciones, e INYECTAR datos al agente de ventas.
Lo que YA EXISTE y no tocar:
- Tabla order_context_items con TTL 30min (items del pedido actual por conversación)
- Tabla addresses con maps links por cliente
- humanOverrideUntil en conversations table
- getCustomerFullProfile tool en Telegram (combina lead + orders + addresses + context items)
- openai.chat("gpt-5.4-mini") con systemMessageMode developer en ambos agentes
- WhatsApp agent inyecta customerContext + orderContext + addresses en cada mensaje
Lo que HAY QUE IMPLEMENTAR:
1. Tool getConversationContext(conversationId) → devuelve items del pedido actual + direcciones + tipo de cliente + historial reciente de la conversación
2. Tool setHumanOverride(conversationId, enabled) + sendMessageAsOperator(conversationId, text) → para que el admin tome control y mande mensajes como operador humano
3. Tool injectCustomerNote(phone, note) → agrega notas al lead que el agente de ventas ve en el próximo mensaje
4. Actualizar system-prompt del Telegram para que entienda el flujo de ventas (pasos del agente Karen)
Archivos a modificar:

- src/lib/whatsapp/agent.ts (solo lectura para entender el flujo)
- src/lib/whatsapp/prompt-builder.ts (solo lectura para entender los pasos)
